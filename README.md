# ウルトラマン情報ウォッチャー

ウルトラマン関連のイベント・特売情報を1日おきに自動収集し、iPhone の
ホーム画面から PWA として閲覧・通知するための個人用ツールです。

- 収集: GitHub Actions が1日おきに実行
- 閲覧: GitHub Pages 上の PWA（Safari 想定）
- 通知: Web Push で iPhone へ新着件数を送信
- 既報は自動で除外。気になる記事は端末内にピックして後から確認できる

## セットアップ

導入手順は `HANDOFF.md` を参照してください。
設計判断の理由は `DECISIONS.md` にまとめてあります。
